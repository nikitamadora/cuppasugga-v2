- [x] Auth: signup, login, logout
- [x] Create a listing (need/offer, good/service, category, price/volunteer)

## Stretch Features
- [ ] Volunteer interest badges — users tag themselves by category on their profile; surfaced as visual badges
- [ ] Organization profiles — orgs can register, post listings, and be browsed separately from individuals
- [ ] Matching — when a need is posted, surface users with volunteer interest in that category
- [ ] Connections dashboard — see who's responded to your listings, and what listings you've responded to
- [ ] Listing status management — mark your own listing as fulfilled or closed from the profile page
- [ ] Zip-based proximity — show listings near you by default (requires geocoding or zip-radius logic)
- [ ] Search — keyword search across listing titles and descriptions
